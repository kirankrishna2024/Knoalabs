# v3.14.0 (Oct 26 2026)
- **Live analytics was returning HTTP 500 for every request**: the new visitor query used `db` in `src/analytics.js` without importing it. The whole page stayed on "Reconnecting…" and every chart was empty. Fixed, and the UI tests now really load the charts (see below).
- **Browsers**, **Opened inside an app** and **How the source was found** now count *everyone who opened the page* next to the people who registered (new `visitors` block in `GET /admin/api/analytics`, built from `visitors` + `sessions`). A browser or app that sends visitors but no registrations was invisible before, because only leads were counted. The visitor side cannot be split by "I am a", channel or medium (a visitor has not answered), so it follows the period, master class and campaign; that is stated in the card help text.
- **Full screen no longer covers other controls**: the button bar was positioned over the top-right corner of every card, so it sat exactly on **Show leads** (clicks landed on Full screen) and on **Close** in the leads pop-up. It is now part of the card's normal layout.
- **Where people come from**: the period buttons were in a scrambled order (JavaScript lists integer-like object keys first); they now read Today, Last 24 hours, Yesterday, Last 2 days, 7, 14, 30, 90 days, All time, Same as the page period. The map opens on **Same as the page period** so it never disagrees with the KPIs above it. **India** now frames Kerala to Kashmir (it stopped at about 19°N and cut off the whole south). Each layer has its own dot scale and visitors who did not register are rings, so the green registered dots stay visible where both layers share a city. Full screen is a 2:1 box: 697 px tall at 1440×1000 instead of 600 px with letterboxing.
- **Phone layout**: the tab strip scrolls inside itself instead of making the whole page 551 px wide on a 390 px screen (document width 551 px → 390 px).
- **Copy**: "No students in this period" was shown while students existed (they had simply not answered the breakdown questions); it now says which answers are missing.
- **Tests**: the jsdom screen tests were silently asserting on empty charts — page `fetch` calls carried a jsdom `AbortSignal`, which Node's `fetch` rejects ("Expected signal to be an instance of AbortSignal"). `test/fixtures/fetch.js` bridges the signal; the analytics charts, the map and the leads pop-up are now really exercised (26 insights checks, 8 leadview screen checks). New checks: visitor vs registered browsers/apps/source methods, the map period order and default, and India covering Kerala.
- `checks/admin-api-paths.txt` and `checks/healthy-paths.sh`: the analytics fields / leads / Excel, insights, link-lookup and the new assets.

# v3.13.0 (Oct 26 2026)
- **Websites that sent visitors** is now a real bar graph (link opens + registrations per website, redirects such as t.co / l.instagram.com flagged, click a row to filter). Before, it only counted registrations, so a site that sent visitors but no leads never appeared. Source: `detected.hosts` in /admin/api/analytics. Note: the site is only known when the visitor's browser sends a referrer; WhatsApp, QR scans, many in-app browsers and typed addresses send none.
- **Show leads** opens a pop-up (Esc / click outside closes) on every entry point (button, filter bar, campaign table). Shows a loading message and the real error, and when the selection has only visitors who did not register it switches to "Registered + did not register" by itself instead of an empty table.
- **Where people come from**: opens on **Today**; periods Today, Yesterday, Last 24 hours, Last 2 days, 7, 14, 30, 90 days, All time, Same as page. Every state / province of every country (4,400 outlines, 201 countries, Natural Earth 10m) plus country borders. Visitors who did not register are solid amber dots drawn on top of the green registered dots. People whose lookup gave only a state or country (no city) are drawn at the middle of that state / country ("area only"). Country, state and city lists are longer and scroll.
- src/compress.js: MAX_BUFFER 2 MB -> 8 MB so states.json (2.5 MB) is compressed (about 800 KB on the wire).
- Rebuild map data: `node scripts/build-world-map.js` and `node scripts/build-states-map.js ne_10m_admin_1_states_provinces.geojson`.
- New test: test/fixes.test.js.
