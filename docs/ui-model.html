3. Responsive behaviour

Phone (form < 520px, dashboard < 720px) · form: one column, "I am a" cards stack, pills 2-up. Dashboard: counts 2×2, rows become labelled cards, filters 2-up, Clear full width.

Tablet (form 520px+, dashboard 720–1100px) · form: centred 640px card, names side by side, pills 4-up. Dashboard: counts 4-up, charts 2-up, filters 3-up, table scrolls sideways if needed.

Laptop > 1100px · dashboard at full width (max 1280px): 4 counts, 14-day chart + two rankings, one-row filters, full table. Form stays one centred card.

4. Dashboard pieces (leads + live analytics)

What the admin sees at /admin: counts first, then the 14-day trend, then the two rankings, then the filter toolbar and the table. Numbers arrive from /admin/api/stats and are retried twice on their own; only a failure that persists shows the red banner with Try again — a count is never silently left at –.
